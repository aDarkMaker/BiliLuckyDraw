功能特性 ​

实时弹幕抽奖 ​

连接直播间后，应用会持续监听弹幕。观众发送的弹幕只要包含你设定的口令，就会被自动加入抽奖池——不需要主播或房管手动记名单。同一位观众在同一直播间多次发言只会被计入一次，保证机会均等。

口令留空即「全弹幕收集」：所有发言观众都入池，选人页会明确标出当前模式。开奖时从池中随机抽取指定数量的中奖者，结果同时写入当前配置的历史记录。

边看边抽 ​

选人页把直播画面、频道列表和弹幕流放在同一屏：

  • 直播画面：内嵌 HLS 播放器，跟随当前选中的频道；未开播时显示封面。
  • 频道列表：列出已加入的频道，显示主播、在线人数与开播状态，点一下即可切换预览。
  • 实时弹幕：显示当前频道的弹幕流，支持 B 站内置表情（含 [oh] 这类口令表情）。

弹幕区默认贴底跟随新消息；手动向上滚动后停止自动定位，静置约 3 秒后自动恢复贴底。新弹幕会批量合批刷新，避免刷屏时逐条重渲染。

频繁直播的稳定性 ​

  • 播放器看门狗：部分直播流会静默卡住（没有 error / stalled 事件，currentTime 不再前进）。播放器每秒检查播放时钟，连续 5 秒无进展时先尝试软恢复，仍失败则重建播放器并换新的播放地址，退避上限 20 秒。
  • 弹幕断线重连：弹幕 WebSocket 断开后按退避重连，握手时携带登录态与 buvid3，避免昵称被打码、UID 归零导致所有观众合并成同一人。

两种登录方式 ​

  • 凭证登录：从浏览器复制 B 站 Cookie，粘贴后即可登录。
  • 扫码登录：点击「扫码登录」生成二维码，用 B 站手机客户端扫描即可，无需手动复制 Cookie。二维码有过期与已扫描状态提示，可随时重新获取。

多套抽奖配置 ​

为不同场景各存一套配置（Profile），每套独立保存口令、中奖人数、加入的频道和背景图。切换配置时这些设置一起切换，互不干扰，自动保留。

抽奖历史与导出 ​

每次开奖都会自动记录一条历史，绑定在当前配置下——包含口令、中奖人数、开奖时间和完整中奖名单。设置页的「历史」页签可以：

  • 单条导出：把该次中奖名单导出为 Markdown 文件，文件名为 口令-人数-时间.md，内容为「昵称 + UID」的表格。
  • 单条删除：删除不需要的历史记录。
  • 全部删除：清空当前配置下的全部历史（有确认弹窗）。

切换配置时历史列表自动切换；删除某套配置时，其历史一并清除。每个配置最多保留最近 100 条。

界面与主题 ​

  • 深浅色：可手动切换，首次启动跟随系统偏好，选择自动记住。
  • 背景：可选「默认」渐变、春节或假日背景图；也可上传自己的图片作为背景。
  • 主色调：从当前背景图采样提取主色，自动生成整套 primary 色阶，四个页面跟着同一套颜色走。
  • 语言：内置中文 / English 切换，默认中文。

交互细节 ​

  • 出结果时直播画面保持比例，中选名单只占剩余高度并在卡片内滚动，页面整体不会被撑出滚动条。
  • 面板与列表的滚动条只在滚动时显现，静置后自动淡出。
  • 复制中奖名单优先走浏览器剪贴板，失败时回退到后端原生剪贴板，最后回退到开发桥接的系统命令。
  • 添加频道支持填房间号，也能直接粘贴直播间链接自动解析。
