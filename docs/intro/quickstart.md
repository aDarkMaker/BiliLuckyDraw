# 快速开始

## 1. 下载

从 [Releases](https://github.com/aDarkMaker/BiliLuckyDraw/releases) 下载对应平台的安装文件。

## 2. 登录

支持两种登录方式：

- **Cookie 登录**：从浏览器复制 B 站 Cookie，粘贴到输入框，点击登录。
- **扫码登录**：点击「扫码登录」，使用 B 站手机客户端扫描二维码，自动完成登录。

## 3. 配置直播间

进入设置页，添加要监控的直播间房间号。支持同时监控多个直播间。

## 4. 开始抽奖

1. 在顶栏输入关键词（观众弹幕包含关键词即视为参与）。
2. 设置中奖人数（1–9999）。
3. 点击「开始」，程序实时监控弹幕并收集参与用户。
4. 点击「停止」开奖，随机抽取中奖者并展示名单。

## 5. 切换主题 / 语言

在设置页「外观」卡片：

- **主题**：日间 / 夜间 / 春节 / 海滩，分段控件切换。
- **语言**：中文 / English，分段控件切换。

切换后立即生效并持久化。
