# 快速开始

## 1. 下载

前往 [Releases](https://github.com/aDarkMaker/BiliLuckyDraw/releases) 下载对应系统的安装包：

| 平台 | 文件 |
| --- | --- |
| macOS（Apple Silicon / Intel） | `BiliLuckyDraw-darwin-universal.zip` |
| Windows | `luckydraw-amd64-installer.exe`（安装版）或 `luckydraw.exe`（绿色版） |

macOS 首次打开若被系统拦截，在「系统设置 → 隐私与安全性」里选择仍要打开即可。

## 2. 登录

启动后选择一种方式登录 B 站账号：

- **凭证登录**：从浏览器复制 B 站 Cookie，粘贴到输入框后点击登录。
- **扫码登录**：切换到「扫码登录」生成二维码，用 B 站手机客户端扫一扫，并在手机上确认。

登录凭证只保存在本机 `~/.luckydraw/config.json`。

## 3. 添加频道

进入「设置 → 选人」，把要监控的房间号填进去；也可以直接粘贴直播间链接，例如 `https://live.bilibili.com/12345`。支持添加多个频道，所有参与者汇总到同一个抽奖池。

回到「选人」页，右侧频道列表会显示每个频道的封面、主播和在线人数，点一下切换预览。

## 4. 开始抽奖

在选人页设置弹幕口令和中选人数（1–9999），然后点「开始选人」。观众发送含口令的弹幕后，参与人数会实时上涨：

- 口令留空 = 收集全部弹幕。
- 弹幕区会同步显示当前频道的弹幕；向上滚动可回看，几秒后自动回到最新。
- 想开奖时点「停止选人」，随机抽出的中奖名单立刻展示，并自动记入历史。

中奖人数较多时，名单在卡片内滚动，不影响页面整体布局。

## 5. 查看与导出历史

设置页的「历史」页签按当前配置列出开奖记录：

- 点「导出」把该次名单保存为 Markdown（`口令-人数-时间.md`）。
- 可以单条删除，或点「全部删除」清空当前配置的历史。

## 6. 切换外观与语言

设置页的「界面」页签可以切换深浅色、背景（默认渐变 / 春节 / 假日 / 自定义图片）和语言（中文 / English）。切换立即生效并自动记住。

::: tip 快捷键提示
侧栏可以在窄窗口下收起；弹幕与中奖名单的滚动条只在滚动时出现，避免干扰视线。
:::
