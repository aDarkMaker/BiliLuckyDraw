# 快速开始

## 1. 下载

前往 [Releases](https://github.com/aDarkMaker/BiliLuckyDraw/releases) 下载对应系统的安装包，打开即可运行。

## 2. 登录

启动应用后，选择一种方式登录 B 站账号：

- **Cookie 登录**：从浏览器复制 B 站 Cookie，粘贴到输入框后点击登录。
- **扫码登录**：点击「扫码登录」生成二维码，用 B 站手机客户端扫描即可，无需手动复制 Cookie。

## 3. 添加直播间

进入设置页，把要监控的直播间房间号填进去。支持同时添加多个直播间，所有参与者会汇总到同一个抽奖池。

## 4. 开始抽奖

回到首页，在顶栏设置参与关键词和中奖人数，然后点「开始」。观众发送含关键词的弹幕后，参与人数会实时上涨；想开奖时点「停止」，随机抽出的中奖名单会立刻展示出来。中奖人数较多时，名单会在卡片内滚动，不影响页面整体布局。

## 5. 查看与导出历史

每次开奖都会自动记录到当前配置的历史里。进入设置页，在「抽奖历史」卡片可以查看：

- 点击某条历史的「导出」，选择保存位置，中奖名单会以 `关键词-人数-时间.md` 导出为 Markdown。
- 可以单条删除历史，或点「全部删除」一键清空当前配置下的历史。

## 6. 切换主题与语言

在设置页的「外观」里可以切换主题（日间 / 夜间 / 春节 / 海滩）和语言（中文 / English），切换后立即生效并自动记住。
