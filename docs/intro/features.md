# 功能特性

## 直播间抽奖

实时监控直播间弹幕，按关键词匹配收集参与用户，参与者按 UID 去重（同一直播间多次发言只计一次）。开奖时使用 Fisher-Yates 洗牌算法从参与者池中随机抽取指定数量的中奖者。

## 多种登录方式

- **Cookie 登录**：粘贴浏览器 Cookie 直接登录。
- **B 站 APP 扫码登录**：生成二维码，使用 B 站手机客户端扫码，轮询登录状态自动完成登录。

## 多账号 Profile

支持多套抽奖配置（Profile），每套独立保存关键词、中奖数、监控房间、背景图。一键切换，切换后立即生效并持久化到 `~/.luckydraw/state.json`。Profile ID 格式为 `pf_<unixnano>`。

## 主题系统

内置四套主题：

| 主题 | 说明 | 背景图 |
| --- | --- | --- |
| 日间（light） | 默认，跟随系统 `prefers-color-scheme` | 无（支持自定义） |
| 夜间（dark） | 深色界面 | 无（支持自定义） |
| 春节（spring-festival） | 红色半透明毛玻璃 | 主题内置 |
| 海滩（beach） | 蓝色半透明毛玻璃 | 主题内置 |

运行时可切换，选择持久化到 `localStorage`（键 `luckydraw-theme`）。春节 / 海滩主题内置背景图，主题背景优先于用户自定义背景图。

## 可定制

- 自定义关键词（弹幕包含关键词即参与）
- 自定义监控房间（支持多个直播间同时监控）
- 自定义背景图（日间 / 夜间主题生效，春节 / 海滩使用主题内置背景）
