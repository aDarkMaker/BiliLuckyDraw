# 功能特性

## 实时弹幕抽奖

连接直播间后，应用会持续监听弹幕。观众发送的弹幕只要包含你设定的关键词，就会被自动加入抽奖池——无需主播或房管手动记录名单。同一位观众在同一直播间多次发言只会被计入一次，保证机会均等。开奖时从抽奖池中随机抽取指定数量的中奖者。

## 两种登录方式

- **Cookie 登录**：从浏览器复制 B 站 Cookie，粘贴后即可登录，适合熟悉操作的用户。
- **扫码登录**：点击「扫码登录」生成二维码，用 B 站手机客户端扫描即可，安全便捷，无需手动复制 Cookie。

## 多套抽奖配置

为不同场景各存一套配置（Profile），每套独立保存关键词、中奖人数、监控房间和背景图。开播前一键切换，互不干扰，自动保留。

## 抽奖历史与导出

每次开奖都会自动记录一条历史，绑定在当前抽奖配置下——包含关键词、中奖人数、开奖时间和完整中奖名单。在设置页的「抽奖历史」卡片里可以查看某套配置下的全部历史：

- **单条导出**：点击某条历史的「导出」，选择保存位置，中奖名单会以 `关键词-人数-时间.md` 命名导出为 Markdown 文件，内容为「昵称 + UID」的中奖表格。
- **单条删除**：删除不需要的历史记录。
- **全部删除**：一键清空当前配置下的所有历史。

切换配置时，历史列表会自动切换到对应配置的记录。删除某套配置时，其下的历史也会一并清除。

## 四套主题

内置四种界面风格，运行时随时切换：

| 主题 | 说明 | 内置背景图 |
| --- | --- | --- |
| 日间（light） | 浅色界面，首次启动跟随系统深浅偏好 | 无（可自定义） |
| 夜间（dark） | 深色界面，护眼 | 无（可自定义） |
| 春节（spring-festival） | 红色调，带毛玻璃与节日氛围 | 是 |
| 海滩（beach） | 蓝色调，带毛玻璃与清新氛围 | 是 |

选择自动记住，下次打开保持不变。春节 / 海滩自带背景图；日间 / 夜间可用自定义背景图。

## 灵活可定制

- 自定义关键词——决定哪些弹幕算参与
- 自定义监控房间——支持同时监控多个直播间，参与者合并到同一个抽奖池
- 自定义中奖人数——1 到 9999 随心设置
- 自定义背景图——日间 / 夜间主题生效（春节和海滩使用自带背景）

## 中奖名单显示优化

中奖人数较多时，中奖名单卡片会限制最大高度，超出部分在卡片内部滚动（滚动条自动隐藏），保证抽奖页面整体不会纵向滚动，视觉始终干净稳定。
