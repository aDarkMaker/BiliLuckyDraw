# Quick Start

1. **Download** — grab the latest build from [Releases](https://github.com/aDarkMaker/BiliLuckyDraw/releases) for your platform (macOS `.app`, Windows `.exe`, Linux binary).

2. **Log in** — launch the app and log in with a Bilibili account via Cookie or QR code (scan with the Bilibili mobile app).

3. **Configure rooms** — open Settings (top-right gear) and add the live room IDs you want to monitor under "Watched rooms".

4. **Start a draw** — back on the home screen, enter a keyword and set the winner count (1–9999) in the top bar, then click **Start**. Danmaku containing the keyword enters the pool; the participant count updates in real time. Click **Stop** to draw and reveal the winners.

5. **Switch theme / language** — in Settings, under "Appearance", pick a theme (light / dark / spring-festival / beach) and a language (中文 / English). Both persist across restarts.
