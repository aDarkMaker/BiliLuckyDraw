# 开发日志

## v1.6.0

界面重构与实时观赛：

- 选人页重做为「直播画面 + 频道列表 + 弹幕流 + 参数条」的单屏布局，窄窗口自动收起侧栏
- 新增实时弹幕面板：跟随当前频道、支持 B 站表情（含 `[oh]` 这类口令表情）、贴底跟随、上滚暂停、静置 3 秒自动恢复
- 新增内嵌直播播放器（HLS），带时钟看门狗：静默卡流时先软恢复，再重建播放器并换地址，退避上限 20 秒
- 主题改为「深浅色 + 背景预设」两层：春节、假日背景可选，主色调从背景图自动取色
- 界面改用 Tailwind + HeroUI，滚动条只在滚动时显现，中奖名单在卡片内滚动
- 图片链路优化：限并发预解码队列、B 站 CDN 缩略图、可见区懒加载，弹幕刷屏时主线程卡顿明显下降
- 前端按功能域拆分（session / lottery / rooms / profiles / settings / history），后端 service 拆分出 room / danmaku_feed / emote / history
- 新增浏览器开发桥接：`/api/*` 与 Wails IPC 共用同一份业务代码，独立二进制 `cmd/devbridge` 复用同一路由
- 登录页支持卡片倾斜动效与主题切换；二维码状态机覆盖过期与已扫描待确认
- 口令留空即收集全部弹幕；添加频道支持直接粘贴直播间链接

## v1.5.0

- 抽奖页实时显示参与人数，等待弹幕时有明确提示
- 关键词留空即收集全部弹幕，抽奖页会标明当前模式，无人参与时不再开奖
- 直播间连接失败会明确提示，避免「假装在积累」
- 中奖页支持一键复制名单
- 历史记录改用真实关键词与中奖人数，并只保留最近 100 条
- 网络异常不再误清登录态，配置文件权限收紧为 0600

## v1.4.0

- `getDanmuInfo` 接入 WBI 签名，修复接口返回 `-352` 导致弹幕连不上的问题
- 弹幕握手补全 `uid` 与 `buvid3`，避免昵称被打码、UID 归零后参与者被合并成同一人
- 弹幕主机改用 `wss_port`（2245），旧 `getConf` 兜底路径保留 token 与主机列表
- 修复前端 `tsconfig.json` 多余的 `types` 配置，依赖与绑定缺失时不再报类型错误
